# Pixi playable projects — private backup

Снимок `D:/Pixi` от **8 октября 2026 года**. Сохранены все 12 каталогов проектов:
исходники, конфигурации, package-lock.json, ресурсы и существующие готовые сборки
из dist, включая рекламные HTML/ZIP для разных сетей и локализаций.

## Восстановление

```sh
git clone https://github.com/fixight/pixi-playables-backup.git
cd pixi-playables-backup/pixi-playable9
npm ci
npm run dev
```

Вместо pixi-playable9 выбрать любой нужный каталог. Зависимости устанавливаются
**внутри каждого проекта**, общего package.json в корне нет. Использовать Node.js,
совместимый с Vite 7 (например, Node 22.18+). У K14_18_pixi скрипты запускают
TypeScript непосредственно через Node; его требования смотреть в package.json
и документации используемых playable-scripts.

Сборка обычных Vite-проектов: `npm run build`. Существующие dist сохранены, даже
если локальные .gitignore проектов исключали их. Это готовые результаты работы;
повторная сборка может их перезаписать. Исходники и ресурсы сохранены отдельно.

## Что исключено

node_modules, вложенная история .git, кеши, настройки IDE, журналы и потенциальные
файлы с секретами. Секреты/учётные данные не найдены при подготовке. Исходная папка
D:/Pixi не изменена. Это резервная копия текущего состояния, автоматической
синхронизации с исходной папкой нет.

`backup-inventory.json` содержит полный список сохранённых файлов, исключения,
команды запуска проектов и версии установленных прямых зависимостей.
Вложенные Git-репозитории сохранены как обычные каталоги исходников.

Проверка скачанной копии: `python verify_backup.py`. Она сверяет содержимое с
контрольными суммами первоначального снимка. После намеренных изменений несовпадения
ожидаемы. Функциональная работоспособность всех playable-сборок отдельно не проверялась.
